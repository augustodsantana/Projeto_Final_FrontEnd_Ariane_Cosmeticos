# Ariane \- Cosméticos Natura & Demillus (SPA One Page com Scroll Continuo).

Projeto final desenvolvido para a Unidade Curricular de Front-End.

## 📌 Sobre o Projeto

Realizei este projeto considerando que minha mãe vende produtos cosméticos e seria bacana que ele utilizasse um site como o criado para realizar suas vendas de maneira mais formal e com maior alcance de clientela, uma vez que o site esteja na internet, todos presentes no Brasil poderiam acessá-lo e comprar um produto cosmético. Esta aplicação foi desenvolvida com 4 tecnologias, HTML5, CSS3, JavaScript e Bootstrap.

## ⚡ Recursos Implementados

1. **Rolagem Suave Continua (Smooth Scroll):** Ao clicar nos botões do menu superior (Início, Quem Somos, Produtos, Depoimentos, Contato), a página desliza suavemente até a seção correspondente.  
2. **Scrollspy Ativo:** O item do menu acende destacando em qual seção da página o usuário está no momento.  
3. **Alternador Modo Claro / Escuro:** Alterna o tema da página inteira salvando a escolha.  
4. **Filtro de Produtos Dinâmico:** Filtra os cards sem recarregar a página.
